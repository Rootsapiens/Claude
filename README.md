# Claude Video & Animation Resources

فهرس مصادر لعمل فيديو وأنيميشن باستخدام Claude. Claude لا يولّد فيديو: يكتب كودًا يرسم كل فريم، ثم يُصدَّر MP4. التعديل سطر كود، وليس إعادة توليد.

المحتوى منقول من منشور المستخدم كما هو. الأوصاف (عدد الـ repos، عدد الـ skills، تاريخ الإصدار) لم يتم التحقق منها.

الـ workflow المعتمد: [docs/workflow.md](docs/workflow.md)
الـ skill الجاهز لـ Claude Code: [.claude/skills/video-animation/SKILL.md](.claude/skills/video-animation/SKILL.md)

## 1. الفهارس

- [Awesome Claude Video Skills](https://github.com/zhuyansen/awesome-claude-video-skills): فهرس 170+ repo (motion graphics، explainers، promos، أنيميشن).
- [Awesome Opus 5.5 Videos](https://github.com/athemeroy/awesome-opus-5-5-videos): دراسة 1,500+ بوست، وكيف اتعمل كل فيديو.

## 3. Starter kits للأنيميشن المرسوم

- [ClaudeAnimationBase](https://github.com/JohnHeibel/ClaudeAnimationBase): شخصية جاهزة بـ31 تعبير ودليل أنيميشن.
- [Claude Animation Skill](https://github.com/buildwithhanif/claude-animation-skill): رسم يدوي وألوان مائية بالكود، صوت متولّد، 3 أفلام أمثلة.
- [Lemo Opuscar](https://github.com/lemomo-ai/lemo-opuscar): 39 ستايل سينمائي، لكل ستايل برومبت وفيلم. [معرض الستايلات](https://lemomo-ai.github.io/lemo-opuscar/)
